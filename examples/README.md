# Examples

This folder contains the supported runnable examples for the public Cleanalytix package.

- `simple_usage.py` covers single-dataset data quality analysis and recommendations using `Run_DQ_Pipeline()`.
- `production_usage.py` covers baseline-versus-production monitoring, distribution drift evaluation, and custom business rules using both `cleanalytix.analyze()` and `Run_DQ_Pipeline()`.

Historical prototype material is kept separately in [`archive/legacy`](../archive/legacy).
